## Limits and handoff

- Chromium viewport resizing is not physical touchscreen/device testing. Actual touch scrolling, long-press behavior, and other browser engines remain unverified. Hover text was checked via Chromium's real hovered state following a click; timed pointer-entry/gap behavior is covered by unit tests rather than automated native hover movement.
- Browser acceptance used the development server; the production bundle was successfully built but was not served for a separate full production-browser run.
- In this restricted subprocess, default Git status incorrectly reported no work tree, and default Vite startup failed EPERM on its temporary config bundle. Elevated commands against the same authorized managed checkout succeeded without changing Git configuration. Initial in-app browser creation with an explicit visibility flag was unsupported for subagents; creating the tab without that flag succeeded.
- The build's large-chunk advisory and Git line-ending advisories remain. No lint warnings remain. There are no failing or skipped automated tests.
- No SFX files were supplied or substituted. Use the manifest handoff in README when the user provides paths. No Currency or Carried Load behavior was changed.
